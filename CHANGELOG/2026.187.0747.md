# Schema compaction — compact node grammar + SSH port auto-allocation

`charly migrate` (compact-node-form, schema 2026.186.2323) reshaped every
charly.yml to the compact grammar: collections inline in the kind value, steps
as ordered `plan:` lists, the plugin envelope rewritten to the `<word>: <input>`
sugar, live-verb exclusive fields folded into their verb input maps, `env:`
lists → maps. Full `charly box validate` green against the new loader; the pinned
`@github` superproject refs resolve via remote-cache auto-migration.

The check-arch-* VM beds now AUTO-ALLOCATE their SSH host port
(`ssh: {port_auto: true}`) instead of a hardcoded `1222x` port, so they run in a
parallel bed roster without host-port collisions (a concurrency fix — the runner
probes a free port and persists it in vm_state).
