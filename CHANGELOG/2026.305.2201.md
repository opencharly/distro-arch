# 2026.305.2201 — fix(pins): advance the layer-charly ref off v2026.274.0345, whose charly=2026.268.1917 package pin is no longer served

## Summary

`layer-charly:v2026.274.0345` hardcodes `charly=2026.268.1917`, and that package is no longer served by `charly-arch` (opencharly/layer-charly#15). Any build resolving this ref dies at its pacman install step with `error: target not found: charly=2026.268.1917`.

This advances **the one `layer-charly` ref in this repo** — `box/check-agent-box/charly.yml:13`, the `check-agent-box` image, whose own `base:` line reads `arch` — from `v2026.274.0345` (as committed on `main`) to **`v2026.292.2352`**, superseding the round-1 head `7ddfa87` that stopped at `v2026.281.2113`.
